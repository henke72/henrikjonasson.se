# henrikjonasson.se

Static personal site, served by GitHub Pages from the `main` branch root.

- `index.html` and `style.css` are the whole site; no build step.
- `CNAME` holds the custom domain. Do not remove it, or Pages drops the domain.
- `.nojekyll` makes Pages serve the files as they are.
